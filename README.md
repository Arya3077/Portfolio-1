# 💻 Portfolio Website — Arya Shibu Dhanya

A personal portfolio website showcasing frontend engineering, modern web applications, and UI/UX implementation. Built with **React.js**, **Tailwind CSS**, and **Framer Motion**, featuring editorial typography and responsive motion design.

---

## 🌟 Key Highlights
- **Home Section:** Introduction, dynamic typing subtitle, availability badge, subtle parallax ambient glow, and magnetic CTAs.
- **About Section:** Background summary, core frontend engineering competencies, and interactive technical skills display.
- **Experience Section:** Career timeline highlighting frontend internship contributions and production platform implementations.
- **Projects Section:** Typographic editorial cards for:
  1. **ASTRAL** — Astronaut Health Monitoring Dashboard
  2. **Clinic Management System** — Healthcare records & appointment portal (Supabase & Firebase)
  3. **AI Evolve** — Official community event platform (μLearn Foundation)
- **Contact Section:** Direct contact form with email client dispatch and social profile connections.
- **Motion & Accessibility:** Framer Motion scroll progress indicator, magnetic hover feedback, entrance reveals, spring click confirmation, and complete `prefers-reduced-motion` compliance.
- **Dark Mode:** Seamless light/dark theme switching with persistent system state.
